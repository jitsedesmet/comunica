# Comunica Config Materialize RML

[![npm version](https://badge.fury.io/js/%40comunica%2Fconfig-materialize-rml.svg)](https://www.npmjs.com/package/@comunica/config-materialize-rml)

Default configuration files for [Comunica Materialize RML](https://github.com/comunica/comunica/tree/master/engines/materialize-rml).
They configure only the actors that evaluate the plan of an RML mapping, reusing those of
[`@comunica/config-query-sparql`](https://github.com/comunica/comunica/tree/master/engines/config-query-sparql) where possible.

This module is part of the [Comunica framework](https://github.com/comunica/comunica),
and should only be used by [developers that want to build their own query engine](https://comunica.dev/docs/modify/).

[Click here if you just want to query with Comunica](https://comunica.dev/docs/query/).

## Install

```bash
$ yarn add @comunica/config-materialize-rml
```
